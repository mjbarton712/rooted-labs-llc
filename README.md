# Rooted Labs LLC

A simple, clean landing page for Rooted Labs LLC - showcasing our company and portfolio.

## About

Rooted Labs LLC is a technology company focused on creating innovative web applications. Our flagship project is [CulinaryCard.app](https://culinarycard.app).

## Project Structure

```
rooted-labs-llc/
├── index.html          # Main HTML file
├── styles.css          # Stylesheet
├── script.js           # JavaScript for interactions
├── assets/             # Images and media
│   └── logo.png        # Company logo (add your logo here)
├── .gitignore          # Git ignore file
└── README.md           # This file
```

## Setup

1. **Add Your Logo**: Place your company logo as `logo.png` in the `assets/` folder
2. **Customize Content**: Edit `index.html` to update company information
3. **Preview Locally**: Open `index.html` in your browser

## Deployment

### GitHub Pages
1. Push this repository to GitHub
2. Go to repository Settings > Pages
3. Select main branch as source
4. Your site will be live at `https://[username].github.io/rooted-labs-llc`

### Vercel
1. Install Vercel CLI: `npm install -g vercel`
2. Run `vercel` in the project directory
3. Follow the prompts to deploy

Or use the Vercel web interface:
1. Go to [vercel.com](https://vercel.com)
2. Import your GitHub repository
3. Deploy with default settings

## Development

This is a static HTML/CSS/JavaScript site with no build process required. Simply edit the files and refresh your browser to see changes.
